# CQELS MCP Server

The CQELS MCP server is distributed as a platform archive on the
[CQELS-RS GitHub Releases](https://github.com/cqels/CQELS-RS/releases) page.

Download the archive matching your target, verify its adjacent checksum, and
run the extracted `cqels-mcp` executable as a stdio MCP server. The server
implementation is not mirrored in this public repository.
